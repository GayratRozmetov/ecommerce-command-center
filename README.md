# E-Commerce Command Center

A modern, interactive operations dashboard for monitoring orders, inventory, products and commerce performance from one focused interface.

> **Portfolio project:** all customers, orders and metrics shown in the dashboard are fictional demonstration data.

## Highlights

- Executive commerce metrics for revenue, orders, average order value and conversion
- Interactive revenue performance chart
- Order search and status filtering
- One-click order workflow updates
- Product performance and inventory overview
- Low-stock alerts for operational attention
- Responsive desktop and mobile interface
- No API key or paid service required

## Interactive Demo

The dashboard includes realistic operational interactions:

- Search orders by ID, customer or country
- Filter orders by processing, shipped and delivered status
- Advance an order through its fulfilment workflow
- Search the product inventory
- Switch the analytics period

## Technology

- React
- TypeScript
- Next.js-compatible App Router
- Vinext / Vite
- CSS
- Cloudflare-compatible worker build

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Production Build

```bash
npm run build
```

## Project Purpose

This project demonstrates how a modern e-commerce team can combine sales analytics, fulfilment visibility and inventory monitoring in one commercial-grade dashboard.
